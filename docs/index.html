A few useful details

Before you press play.

Which Android versions are supported?

Virex Music supports Android 8.0 (API 26) and newer. The current release is version 1.3.3.

Can I listen without internet?

Yes. Download songs or a playlist first, then play saved tracks from the Offline tab. Catalog searches and new streams require a connection.

How do I install the app?

Download Virex-Music.apk from the official GitHub release, open it on your Android device, and follow the installation prompts. Requires Android 8.0 or newer.

Are all songs, lyrics, and radio recommendations always available?

No. Catalog, audio and lyrics depend on external services. Availability and quality vary. Radio includes an artist-search fallback when suggestions are unavailable.

Where can I send feedback?

Use GitHub Issues. Include the app version, Android version, device model and steps to reproduce the problem. Never include private signing keys or passwords.
